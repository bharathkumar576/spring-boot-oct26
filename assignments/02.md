## Spring Boot Assignment: Building REST Services

This hands-on assignment will test your understanding of **Spring MVC REST controllers**, **CRUD operations**, and **proper HTTP status codes**.

---

### Scenario: Product Catalog Service

You are building a simple product catalog microservice that exposes REST endpoints to manage products in memory (or backed by a repository of your choice).

---

### Part 1: Product Model

**Objective:** Define the JSON resource exchanged by the API.

1. **Create a `Product` model** with the following fields:
   * `productId` (Long)
   * `name` (String)
   * `description` (String)
   * `price` (Double)
2. Use Lombok (`@Data` or getters/setters) or write them manually.

---

### Part 2: ProductController

**Objective:** Implement a REST controller exposing CRUD endpoints under `/api/products`.

| Method | Endpoint              | Description                      | Success Status       |
|--------|-----------------------|-----------------------------------|-----------------------|
| GET    | `/api/products`       | List all products                 | 200 OK                |
| POST   | `/api/products`       | Create a new product              | 201 Created           |
| GET    | `/api/products/{id}`  | Find a product by id              | 200 OK / 404          |
| DELETE | `/api/products/{id}`  | Find and delete a product by id   | 204 No Content / 404  |

1. **Annotate** the class with `@RestController` and `@RequestMapping("/api/products")`.
2. **Use `@RequestBody`** to bind the JSON payload for the create endpoint.
3. **Use `@PathVariable`** to extract the `id` for the get-by-id and delete endpoints.
4. **Return `ResponseEntity<>`** so you can control status codes explicitly (e.g., `404 Not Found` when a product doesn't exist).

---

### Part 3: Service Layer & Storage

**Objective:** Keep the controller thin by delegating logic to a service.

1. Create a `ProductService` (annotated `@Service`) that stores products in an in-memory `Map<Long, Product>` or `List<Product>`.
2. Implement methods: `getAllProducts()`, `createProduct(Product)`, `getProductById(Long)`, `deleteProduct(Long)`.
3. Inject `ProductService` into `ProductController` via constructor injection.

---

### Part 4: Validation & Error Handling (Advance Level)

**Objective:** Make the API robust.

1. Add Bean Validation annotations (`@NotBlank`, `@NotNull`, `@Positive`) on the `Product` fields and `@Valid` on the controller's `@RequestBody` parameter.
2. Create a custom `ProductNotFoundException` and handle it with a `@RestControllerAdvice` / `@ExceptionHandler` that returns a meaningful error response with `404 Not Found`.

---

### Deliverables

* Fully functional Spring Boot application exposing the endpoints above.
* Brief written answers: Why return `ResponseEntity` instead of the raw object? What status code should `POST /api/products` return, and why not `200 OK`?
