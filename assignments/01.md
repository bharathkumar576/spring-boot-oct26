## Spring Boot Assignment: Autowiring and Bean Scopes

This hands-on assignment will test your understanding of **Spring Autowiring** (handling multiple implementations) and **Bean Scopes** (Singleton vs. Prototype).

---

### Scenario: The Smart E-Commerce Order Hub

You are building an order processing module for an e-commerce platform. The system needs to choose different shipping providers dynamically and track shopping carts with correct bean lifecycles.

---

### Part 1: Advanced Autowiring & Qualifiers

**Objective:** Learn how to manage ambiguous dependencies using `@Primary` and `@Qualifier`.

1. **Create an Interface:** Create a `ShippingService` interface with a method `String calculateShippingCost(double weight);`.
2. **Implement Multiple Services:**
* Create `ExpressShippingService` (implements `ShippingService`) and annotate it with `@Primary`.
* Create `StandardShippingService` (implements `ShippingService`).


3. **Inject via Constructor:** Create an `OrderCheckoutService` that injects `ShippingService` via its constructor.
4. **Use `@Qualifier`:** Write a secondary test case or inject `StandardShippingService` explicitly using the `@Qualifier` annotation.

---

### Part 2: Bean Scopes (Singleton vs. Prototype)

**Objective:** Observe the difference between default singleton behavior and prototype scope.

1. **Create a Prototype Bean:** Create a class named `ShoppingCart` and annotate it with `@Scope("prototype")`. Add a list of items and a method `addItem(String item)`.
2. **Create a Singleton Service:** Create a service named `SessionManager` annotated as a standard `@Service` (Singleton by default). Inject the `ShoppingCart` bean into `SessionManager` using constructor injection.
3. **The Experiment:**
* Create two different controller endpoints or command-line runners (`CommandLineRunner`).
* Fetch the `ShoppingCart` from two different places or requests and print their memory hash codes (`System.identityHashCode(cart)`).
* **Question to answer:** Do both components share the exact same `ShoppingCart` instance, or are they different? Why does injecting a prototype bean into a singleton bean require special care (e.g., ObjectFactory or Lookup)?



---

### Deliverables

* Fully functional Spring Boot application structure (or a single scratchpad project containing these classes).
* Brief written answers to the scope experiment question.
